## Architecture

| Component | Description |
|:--|:--|
| **Core** | Cosmos SDK modular blockchain architecture |
| **EVM** | Ethereum Virtual Machine and ERC-20 integration |
| **IBC** | Inter-blockchain communication and transfers |
| **Ledger** | Persistent blockchain ledger and state storage |
| **Native Asset** | LFX token integration |

## Development Status

LIMFXAI Layer 1 is under active development.

Core keepers, EVM integration, IBC components, and ledger infrastructure are being implemented and tested.

Application bootstrap, complete genesis workflow, node startup, and production network are not yet complete.

> This project is not currently a production blockchain network.

## Repository Structure

- `chain/` — Blockchain implementation, ledger, EVM, and IBC.
- `formal/` — Formal verification experiments.
